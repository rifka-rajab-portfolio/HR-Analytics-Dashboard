## **Project Overview**

This project focuses on analyzing employee data using Microsoft Power BI. The dashboard provides insights into employee demographics, department distribution, salary trends, and employee attrition to support HR decision-making.

## **Tools & Technologies**

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel / CSV Dataset

**Dataset:**
100 fictional employee records used for data analysis and visualization.

## **DAX Measures**

Created DAX measures to calculate:

- Total Employees
- Active Employees
- Attrition Count
- Attrition Rate
- Average Salary
- Average Age

## **Key Skills**

Data Cleaning | Power Query | DAX | Data Visualization | Dashboard Development

## **Project Files**

- `HR Analysis.pbix` – Power BI dashboard.
- `HR_Analytics_100_Employees.csv` – Employee dataset.
- `HR_Analytics_Dashboard.png` – Dashboard preview.

## **Conclusion**

This HR Analytics Dashboard demonstrates practical skills in data analysis, data cleaning, DAX calculations, and interactive dashboard development using Microsoft Power BI.

**Note:** This project uses fictional employee data for educational and portfolio purposes.
